# Usage

Simple Scaffold can be used as a **CLI tool** or as a **Node.js library**. Both approaches share the
same core concepts: templates, configuration files, and Handlebars-based token replacement.

- [Templates](./01-templates.md) — how template files and directories work, built-in helpers, and
  custom helpers
- [Configuration Files](./02-configuration_files.md) — reusable scaffold definitions,
  auto-detection, inputs, and remote Git templates
- [CLI](./03-cli.md) — all commands, flags, interactive mode, and hooks
- [Node.js API](./04-node.md) — programmatic usage, full config interface, and hooks
- [Examples](./05-examples.md) — end-to-end examples for CLI and Node.js
- [Migration](./06-migration.md) — upgrading from v1.x or v0.x to the latest version
